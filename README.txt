OpenPlay - build steps
1. Install Android Studio (free): developer.android.com/studio
2. File > Open > choose this OpenPlayApp folder. Let Gradle sync finish (needs internet).
   If asked to upgrade or download Gradle/SDK 34, accept.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Click "locate" in the popup. The file is app-debug.apk.
5. Copy it to your phone, open it, and allow "Install unknown apps".

The player itself is app/src/main/assets/index.html - edit it to change features.
